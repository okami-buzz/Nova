# NOVA Roadmap

Tentative roadmap. Every feature should include tests and documentation.

## v0.0.1 — First working core
- [x] C-based interpreter
- [x] `say` statement
- [x] Number and string literals
- [x] Arithmetic precedence and parentheses
- [x] Line-aware errors
- [x] Build instructions and smoke tests

## v0.0.2 — Variables
- [ ] Decide declaration and assignment syntax
- [ ] Add a dedicated environment/symbol-table module
- [ ] Test names, reassignment and invalid values

## v0.0.3 — Types and expressions
- [ ] Define booleans and value types
- [ ] Specify string behavior and conversions
- [ ] Improve diagnostics

## v0.0.4 — Conditions
- [ ] Design `if` / `else` syntax
- [ ] Add comparisons and boolean expressions
- [ ] Add regression tests

## v0.0.5 — Loops
- [ ] Design loop syntax
- [ ] Add tests and safe interruption behavior

## Later
- Functions and modules
- File and JSON libraries
- Networking and web APIs
- Optional AI integrations through libraries
- Formatter, debugger and package manager
- Consider bytecode or compilation after language semantics stabilize
